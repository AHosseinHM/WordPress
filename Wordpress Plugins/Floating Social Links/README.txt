Floating Social Links
Author: Amirhossein Hosseinmardi

FEATURES
- Floating button that expands to display your social and contact links.
- Up to 50 links, displayed in the order they appear in settings.
- Custom button text, color, position (bottom right or bottom left), and bottom offset.
- Custom icon images for each link: upload or select an image from the WordPress Media Library, or enter an image URL.
- Optional built-in symbolic icons (emoji).
- Smaller button on mobile devices.
- Smooth opening and closing animations that respect the device's reduced-motion preference.
- Close the list by clicking outside it or pressing Escape.
- No bundled third-party libraries, external service dependencies, or tracking.

CUSTOM ICONS
Custom images take priority over symbolic icons. Clear the image field to use the selected symbolic icon again.
Recommended format: square PNG or WebP images with a transparent background.
This plugin does not enable SVG uploads.
Images hosted on external URLs are loaded from their respective hosts.

INSTALLATION
1. In WordPress, go to Plugins > Add New Plugin > Upload Plugin.
2. Upload the plugin ZIP file and install it.
3. Activate the plugin.
4. Go to Settings > Social Links Button (shown as "دکمه شبکه‌های اجتماعی" in the current Persian interface).
5. Add your links and save the settings.

UPDATING
Upload the new plugin ZIP file and confirm replacement of the installed version.
Your existing settings are preserved.
If your site uses a caching plugin, clear the cache after saving changes.

NOTES
- Save at least one valid link and enable the button for it to appear.
- The widget appears on front-end pages where the theme calls wp_footer().
- Choose a button color with sufficient contrast against white text.
- Deleting the plugin does not remove its saved settings.
- The plugin interface is currently in Persian.

REQUIREMENTS
WordPress 6.0 or later.
PHP 7.4 or later.
