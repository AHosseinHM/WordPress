1_ هر سه فایل رو داخل هاست سایت در یک پوشه در کنارهم آپلود کنید.
2_ به ووکامرس ← تنظیمات ← پیشرفته ← REST API بروید.
3_ یک API KEY با دسترسی خواندن و نوشتن بسازید.
4_ Consumer Key و Consumer Secret رو کپی کنید.
5_اطلاعات اتصال رو وارد کنید و روی تست اتصال بزنید.
6_ فایل CSV یا محصولات رو دستی وارد کنید.
7_ بستگی به قدرت هاست خود تعداد دسته ها را وارد کنید. (بهتر است برای هاست های معمولی روی 3 بزارید تا بدون ارور اجرا شود.)
8_روی شروع ورود بزنید.
